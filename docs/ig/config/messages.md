# 消息配置

文件：`plugins/InoriGuild/messages.yml`

## 说明

| 项目 | 说明 |
|------|------|
| `prefix` | 插件消息前缀 |
| 其余键 | 业务提示文本 |
| 颜色符 | 支持 `&` 颜色代码 |

## 常用占位符

| 占位符 | 说明 |
|--------|------|
| `{guild}` | 公会名 |
| `{player}` | 玩家名 |
| `{role}` | 职位名 |
| `{level}` | 等级 |
| `{amount}` | 数值 |
| `{currency}` | 货币名 |
| `{seconds}` | 秒数 |
| `{score_self}` / `{score_enemy}` | 战局比分 |
| `{winner}` | 战局胜方 |
