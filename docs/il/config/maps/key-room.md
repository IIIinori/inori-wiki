# key-room.yml

## 示例

```yaml
key-rooms:
  default:
    pos1: "120, 64, 210"
    pos2: "124, 68, 214"
    interact: "122.5, 65, 212.5, 0, 0"
    key: slums_gate_key
    key-consume: 1
```

| 字段 | 说明 |
|------|------|
| `pos1` | 清障区域角点 1 |
| `pos2` | 清障区域角点 2 |
| `interact` | 交互坐标 |
| `key` | 交互所需钥匙 ID |
| `key-consume` | 每次交互消耗的钥匙耐久 |
