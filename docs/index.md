## 选择说明

如果你要配置物品、钥匙、奖池、仓库、保险箱、Raid 或常驻地图，请查看 **InoriLoot**。

如果你要配置商店、交易行、动态价格、自定义货币或交易表达式，请查看 **InoriLootShop**。
